# 播客精選集落地頁專案

本專案為純靜態 HTML/CSS/JS 播客 Landing Page，無後端、無第三方框架。
![](./public/assets/images/home.png)


## 結構
- public/index.html：首頁，顯示三集精選
- public/episode-1.html ~ 3.html：各集詳細頁
- public/assets/images/：封面圖與預設圖
- public/styles/main.css：全站樣式
- scripts/main.js：資料渲染與互動

## 開發
直接以瀏覽器開啟 public/index.html 測試。
